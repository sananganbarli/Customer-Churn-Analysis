# Customer-Churn-Analysis
Customer Churn &amp; Retention Analytics Dashboard built in Excel/Power BI to analyze customer acquisition, churn rates, and regional manager performances.
![Dashboard Preview](Screenshot%202026-10-21%20153635.png)


## Project Overview
This project presents an interactive **Customer Churn Analysis Dashboard** designed to identify at-risk customers, analyze churn drivers, and track key retention metrics. The solution helps business stakeholders uncover behavioral patterns and take proactive steps to reduce customer attrition.

---

## Key Metrics & Analytical Features
* **Churn Rate & Attrition Overview:** Tracks overall customer churn percentage, active vs. churned user counts, and revenue loss impact.
* **Behavioral & Demographic Segmentation:** Analyzes churn rates across customer tenure, service usage types, contract tiers, and geographic regions.
* **Risk Factor Breakdown:** Identifies primary correlations between customer complaints, support ticket frequencies, and cancellation trends.
* **Interactive Filtering:** Enables dynamic slicing by **Time Period**, **Customer Segment**, **Geography**, and **Subscription Plan**.

---

## Tools & Technologies
* **Analytics Platform:** Power BI
* **Data Processing & Modeling:** DAX Measures, Calculated Columns, Time Intelligence
* **Visuals:** Donut Charts, Stacked Bar Charts, KPI Cards, Matrix Tables
